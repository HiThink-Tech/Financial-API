# 示例与灵感

这里是同花顺金融数据服务 monorepo 的示例导航，分为可执行 Python 学习路径和可直接交给 Agent 的金融看板灵感。

- Python 可执行示例：[`../python/examples/`](../python/examples/README.md)
- 可直接浏览和复制 Prompt 的静态灵感：[`inspirations/`](inspirations/README.md)

灵感内容属于 monorepo 级静态资产，不要求安装 Python 子项目。使用 Agent 前优先安装
[`hithink-finance` Skill](../skills/hithink-finance/SKILL.md)。索引维护工具位于
[`../python/tools/inspirations/build_index.py`](../python/tools/inspirations/build_index.py)。
